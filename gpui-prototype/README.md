# EasyCommandRunner GPUI

`gpui` 是仓库当前默认开发分支，发布版本从 `v1.0.0` 开始使用 Rust + GPUI。源码目录暂保留 `gpui-prototype/` 名称，避免更换 Cargo 路径、缓存及旧脚本；它不再表示 Qt 的附属发布入口。Qt/C++ 历史版保留独立分支和工作流，不与 GPUI 打包混用。主页见根目录 [README](../README.md)，原生打包与手动发布见 [packaging/README.md](packaging/README.md)。

## 运行

```sh
cd gpui-prototype
cargo run
cargo test --features ui-test
cargo run --features ui-test -- /tmp/ecr-gpui-visual
```

**必须从 `gpui-prototype/` 目录运行 Cargo。** Rustup 根据当前工作目录选择工具链；若在仓库根目录使用 `cargo --manifest-path gpui-prototype/Cargo.toml`，会选中根目录默认的 Rust 1.93，而不是此原型固定的 1.95，导致 `std::hint::cold_path` 不稳定特性报错。从根目录启动时，显式运行 `RUSTUP_TOOLCHAIN=1.95.0 cargo --manifest-path gpui-prototype/Cargo.toml run`。

最后一条命令用 GPUI Kit 的 Metal 离屏渲染生成深浅主题 / 不同窗口尺寸的 PNG 与 JSON 几何数据（仅 macOS 可用，不打开可见浏览器或窗口）。

## 独立 CI

`.github/workflows/gpui.yml` 在 `gpui` 分支的相关文件变更、相关 PR 或手动运行时构建 GPUI；所有 Cargo 命令都在本目录执行并使用 Rust 1.95.0 与 `Cargo.lock`。macOS ARM64 运行完整后端/UI 测试、构建并做离屏视觉检查；Linux x86_64/ARM64 与 Windows x86_64/ARM64 原生 runner 分别运行非截图测试与构建。Linux/Windows 当前没有 GPUI Kit 的 PNG 离屏渲染器，CI 的通过不等同于这些平台的窗口、托盘和 IME 实机验收。

Windows CI 只上传经过启动检查的 `gpui-ci-windows-*-release-exe`：GPUI 的 debug EXE 在运行时会从编译机 Cargo 缓存读取 HLSL shader 文件，离开构建机可能立即退出，绝不可分发。release EXE 的 shader 已内嵌，可作为单文件试用版但仍依赖目标系统运行库及图形环境。macOS/Linux 的 `gpui-ci-*` artifact 仍为原始调试二进制和检查截图，不是可分发安装包。启用 `package_artifacts` 才生成正式 GPUI Portable ZIP／DMG／AppImage 和构建来源信息；普通 CI 不发布 Release，只有独立的 `gpui-release.yml` 手动确认版本后发布。GPUI 不进入 Qt 的 `build.yml`／`release.yml`，也不覆盖历史 Qt Release。工作流还配置了五架构 release 二进制的打包前审计（需原生 runner 验证）：macOS 检查架构和非系统动态库，Linux 输出实际 ELF 依赖/glibc 版本，Windows 检查 debug/release EXE 的架构、GUI 子系统及内嵌图标组。普通 Windows 程序双击不弹控制台；`cargo test` 和 `ui-test` 仍保留控制台诊断。Windows 曾在真实 GUI 启动时因 PE 默认 1 MiB 主线程栈溢出；现在将主线程栈预留改为 8 MiB，并在原生 runner 上分别启动 debug/release、检查主窗口出现，失败时输出退出码及 stderr。PE 元数据检查和无界面测试单独通过不代表干净机器可运行，CI 更不是已签名/已发布的安装包。Qt 工作流已跳过 `gpui` 分支 push，其状态与独立 GPUI CI 应分别查看。

- 独立系统托盘使用 Qt 版同一份 `resources/tray_icon.svg`，菜单有“显示主窗口”和“退出…”；macOS 左键弹菜单，Windows 右键弹菜单且可双击恢复窗口，Linux 使用桌面状态区菜单。托盘可用时关闭主窗口不会退出：macOS 隐藏应用，Windows 隐藏窗口，Linux 因 GPUI 尚无跨 X11/Wayland 的 hide API 而最小化窗口（仍可能保留任务栏图标）。Windows 会检查图标是否实际注册到 Explorer；注册失败或后续丢失时保留／恢复窗口，避免隐身后无法找回。托盘不可用时关闭窗口会正常退出；存在未保存修改时可选择保存并退出、放弃或取消，运行中的命令退出时会被终止。应用菜单和托盘菜单退出使用同一确认流程。macOS 使用系统模板图标自动随菜单栏配色；Windows 使用系统任务栏深浅色，Linux 使用 GTK 系统主题，不受应用内主题切换影响。Linux 图标使用含进程 ID 的独立名称，避免多开时覆盖彼此的图标文件。

标签图标选择器是类似表情面板的**纯图标网格**，搜索框旁提供“随机 SVG”：从当前分类／搜索结果中选择，多个候选时避开当前图标；无结果时禁用，显式保存后持久化。图标网格内置 1818+ 枚 [Lucide（ISC / Feather 衍生图标 MIT）](assets/tab-icons/LICENSE-LUCIDE) SVG 与 12 枚 [Devicon（MIT）](https://github.com/devicons/devicon/blob/master/LICENSE) 品牌图标，支持分类、中文／英文关键字搜索、滚动浏览、鼠标悬停查看图标名称，以及从搜索框按向下方向键进入网格后方向键选择／回车确认；仅渲染可见行。图标**没有主题色底块**：浅色模式仅当前选中标签在主题色高亮上显示白色图标，其他图标直接在侧栏底色上显示深色；深色模式选中标签显示白色，其他图标跟随浅色文字。仍可粘贴本地 `.svg` 路径或公网 HTTPS SVG 地址（品牌标志仍受相关商标规范约束）。只接受不超过 128 KiB 的有效 SVG；禁止脚本、外链资源及跳转下载。自定义 SVG 下载/读取后缓存于标签配置，断网或源文件移动后仍可显示；新图标在显式保存前属未保存修改，非法 SVG 不替换原图标。Qt 版不会显示这些 GPUI 专用字段，若从 Qt 重新保存配置也可能丢弃它们。

运行按钮通过系统 Shell 启动真实子进程；stdout/stderr 按 UTF-8 增量解码后实时写入运行历史（跨读取块的中文/emoji 不破损），可停止进程组，退出码和停止状态显示在历史项中。运行历史仅保留在当前会话；完成的记录可删除，运行中的记录不可删除。当前记录有新输出时默认跟随到最底部，长行自动换行后也显示最新末尾，不再因整段文本刷新跳回顶部。手动向上滚动（滚轮／触摸板、滚动条或键盘）会暂停跟随；后续输出、收起再展开、调整高度／字号及分离／重新停靠都不强制拉走暂停的视口。日志工具栏有“回到底部”图标按钮（已在跟随或无记录时禁用），点击后跳到末尾并恢复自动跟随；新运行或切换记录默认重新跟随。暂停只属于当前会话，不写入配置。其他任务的输出或仅更新状态／标题不重置当前视口，自动滚动不抢走命令输入的焦点或 IME 状态。停靠日志栏有“分离窗口”按钮；独立窗口与主窗口共用同一份历史、实时输出、选中记录、停止与删除操作，点击“停靠”或直接关闭独立窗口均恢复底部停靠，不会停止运行中的命令。同一时间只创建一个独立日志窗口，主窗口菜单可将其重新置前；独立窗口尺寸和位置暂不记忆，重新分离会使用默认尺寸，不写入配置。无托盘时若真正关闭主窗口，程序会退出（不遗留只有日志窗口的进程）。日志输入框聚焦时，`Ctrl+-` 缩小、`Ctrl+=` / `Ctrl++` 放大（macOS 也支持 `Cmd`），每次 1 px，范围 8–32 px；所有历史记录共用该会话字号，不改变命令输入、预览或界面字号。

命令完成后通过 GPUI 原生系统通知接口请求通知：退出码 `0` 为“正常结束”，非零为“运行报错”并显示退出代码和发起运行时的命令名称。每次运行只通知一次，主动停止不发送错误通知；不会把完整命令或日志内容放入通知。Windows 启动时设置独立 AppUserModelID；系统通知权限、勿扰模式或通知服务可能阻止显示。macOS 需从有 bundle identifier 的 `.app` 启动并允许通知，当前直接运行的开发二进制不会显示原生通知。

**仍未接入：**日志复制/保存文件。全部上部标签关闭后左侧列表不再使用选中态白色文字，普通配置仍可辨认和重新打开。对应操作保持禁用或标注，不显示虚假的成功状态。Windows IME / DPI / ARM64，以及 Windows/Linux 实机托盘主题切换和窗口行为仍待验证。

Linux 编译/运行托盘需要 GTK 3 和 AppIndicator 开发包及桌面状态栏支持，例如 Debian/Ubuntu 可安装 `libgtk-3-dev libappindicator3-dev`（也可用发行版提供的 Ayatana 实现）。无托盘宿主的桌面环境可能不显示图标，不应依赖关闭后仍可恢复。

## 版本

`gpui-kit = 0.6.6` 固定使用其兼容的 `gpui-pre = 0.3.6`。本地工具链固定 Rust `1.95.0`（GPUI 使用的 `std::hint::cold_path` 不支持先前的 1.93）。GPUI Kit 不要求本原型启用 JavaScript 扩展；运行时仍是纯 Rust。

设计与验收要求参见根目录 [`DESIGN.md`](../DESIGN.md)。
